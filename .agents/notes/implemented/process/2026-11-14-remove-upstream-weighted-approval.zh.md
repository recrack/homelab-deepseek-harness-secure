# Agent Note: 移除本仓库继承的加权审批

Status: implemented

[English](2026-11-14-remove-upstream-weighted-approval.md) | 中文

## 问题

继承的加权审批工作流给指定的上游评审者 2 分，给其他有写入权限的评审者 1 分，并根据已合并 PR 数增加作者积分。指定评审者的额外权重和生产代码 blame 模型描述的是源项目的评审政策，并非本仓库定义的审批要求。

## 决定

本仓库不发布或要求加权审批分数。移除两个加权审批工作流、分数与 blame 分类代码、计分工作流的 App token 接线、测试脚本和 CI 门禁，以及英文单语排除项。保留独立的 `Policy` 工作流及其 App 接线。若维护者今后需要本地审批门槛，应通过本仓库的 GitHub 评审设置定义。

## 验证

CI 工作流规范检查确认两个发布工作流、计分目录、Python 计分接线和 package 测试脚本均不存在。run-gates 规范检查确认没有 CI 模式会调度已移除的计分套件。

## 考虑过的替代方案

**保留继承的权重。** 指定评审者和生产代码所有权模型属于源项目，不能定义本仓库的评审要求。

**建立本地加权名单。** 这会在没有本地共同评审模型的情况下增加自定义分数；若需要审批门槛，可用 GitHub 原生评审设置表达。

## 后果

此变更进入默认分支后，新 PR 不再收到 `weighted approval` status 或 `weighted approval decision` check run。已有 status 仍附着在已经收到它们的提交上。
